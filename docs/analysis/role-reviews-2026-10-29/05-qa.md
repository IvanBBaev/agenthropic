# agenthropic — Independent QA / Test-Architecture Review (2026-10-29)

> Part of the [role reviews of 2026-10-29](README.md) — lens: **Senior QA / Test Architect (QA)**. Independent senior reviewer, read-only, on `main` at `db3f042`. Findings are de-duplicated and scheduled in [10-synthesis.md](10-synthesis.md).

Static review, read-only. No suites were run; the coverage figures come from the existing `apps/*/coverage/coverage-summary.json` outputs.

## 1. Verdict

The 100% coverage is **mostly meaningful, not theatre**. Mocking is rare and narrow. Assertions are dense and specific: about 8.3k `expect(` calls, 0 snapshots, 0 `.skip/.only/.todo`. The P0 and acceptance tests re-derive ground truth on their own path instead of reading back the value under test. Five static "honesty" guards stop anyone buying coverage with pragmas, excludes or lowered thresholds.

The weak spot is the **input boundary, not the code**. Every fixture in the gated suite is hand-authored synthetic JSONL (`version: '2.0.0'`, `model: 'synthetic-model-a'`). The real-session golden corpus (WP-X1) was never promoted. `annotations/human/` is empty, so the ≥95% hierarchy gate cannot sign. Nothing automated would catch a silent Claude Code format drift that zeroes tokens.

Missing test levels:
- no real-browser E2E
- no property-based or fuzz tests
- no mutation testing (only hand-run "mutations killed")
- no macOS CI leg, although the target is a Mac Mini

Flakiness under load is structural: there is no `testTimeout` anywhere, and real-SQLite plus loopback-socket integration tests run under the default 5 s.

**Quality readiness for v1.0: 6.5 / 10.** Engineering rigor is about 8.5. The score is held down by the missing real-format contract and the uncertified hierarchy gate.

## 2. What is strong (evidence)

- **Coverage cannot be bought.** All five `vitest.config.ts` are at 100/100/100/100 with `include: ['src/**']`. The only excludes are `src/main.tsx` and `src/vite-env.d.ts` in web, and `apps/web/test/honesty.test.tsx` pins both the exclude list and the thresholds. `apps/server/test/coverage-honesty.test.ts` reads source as text and even guards the guard (`expect(FILES.length).toBeGreaterThan(20)`). Real server totals are 2628 lines and 1585 branches, all covered (`apps/server/coverage/coverage-summary.json`).
- **Acceptance test with a real oracle.** `apps/server/test/p0/p0-five-daily-questions.test.ts` (1094 lines):
  - ingests the fixture corpus with the production `runCorpusIngest`, boots the real `buildServer`, drives status through the real watchdog and hook routes, and asks all 5 questions plus an unauthenticated-refusal case;
  - re-derives the dollar summary in plain JS from `token_usage` × `model_pricing` instead of pinning a magic constant;
  - asserts the sign of each figure separately, because `fast-json-stringify` does not validate `minimum: 0` (lines 40–57).
- **The three P0 moat proofs exist as tests** (`apps/server/test/p0/`): token reconciliation with integer equality per session/model/bucket, double replay giving byte-identical state, and DAG rebuild.
- **Negative catalogue.** All 12 scenarios exist as executable tests, in `packages/core/test/negative/` and `apps/server/test/negative/` (testing.md §5).
- **Little mocking.** Counts: core, shared and test-fixtures have 0 `vi.mock`/`vi.fn`. Server has 10 `vi.mock`, all `importOriginal` partials used for fault injection (`node:fs` short write, a `better-sqlite3` close-on-throw). Web stubs only `fetch` and `EventSource` at the global boundary.
- **The real-fs seam is tested.** `apps/server/test/corpus/real-corpus.smoke.test.ts` checks the in-memory fake against the real `nodeCorpusFs`, including symlink escape and `O_NOFOLLOW`. It is hermetic: `mkdtemp`, injected env, no `~/.claude` dependency.
- **Sockets avoid port collisions.** Tests bind `port: 0` on `127.0.0.1` (`realtime-stream.test.ts:40`). Fake timers are used in 13 files, with `vi.useRealTimers()` in `afterEach` (`honesty.test.tsx`).
- **Migration safety tests.** Checksum pinning, edit-in-place detection, atomic rollback, idempotence, and targeted per-migration upgrade tests with data for migrations 8, 11, 13–15 and 18–20 (`migrations.test.ts:139–1341`).
- **Pricing is loud.** An unknown model halts with `PricingError` instead of a silent $0 (RELEASE.md §6).
- **CI ordering is sensible.** The security gate runs first, then typecheck, lint, format, the SPA build as its own gate, tests, and the license gate (`.github/workflows/ci.yml`).
